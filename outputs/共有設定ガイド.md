# 二人で無料共有する設定

1. [Supabase](https://supabase.com/) で無料プロジェクトを一つ作成します。
2. プロジェクトの **SQL Editor** を開き、[supabase-setup.sql](./supabase-setup.sql) の内容を実行します。
3. **Project Settings → API** から `Project URL` と `anon public` key を取得します。
4. [config.js](./config.js) の `supabaseUrl`、`supabaseAnonKey` を埋めます。`room` は推測されにくい二人だけの合言葉（例：`mio-shu-2026-8f4k`）に変更してください。
5. 同じ `outputs` フォルダを無料の GitHub Pages / Cloudflare Pages / Netlify に公開し、そのURLを二人のホーム画面へ追加します。位置情報は HTTPS 公開したURLで使うのが確実です。

二人が同じ URL（または同じ `?room=合言葉`）を開けば、登録後の画面更新時に同じ図鑑を読み込みます。Supabase 無料枠は 1 GB の写真ストレージと 500 MB のデータベースを含みます。無料プロジェクトは1週間アクセスがないと一時停止します。

## 注意

- `service_role` key は絶対にブラウザに置かないでください。使うのは `anon public` key だけです。
- この簡易共有は二人だけの小規模利用向けです。より厳密に非公開化したい場合は、次にログイン機能とアクセス制限を追加できます。
